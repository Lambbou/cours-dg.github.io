💾 Organisation & Cycle Mémoire en C

Décomposition pas à pas de l'allocation d'un buffer dynamique, de son remplissage via l'arithmétique des pointeurs, de sa libération et de la sécurisation du pointeur contre les accès suspendus.

💻 Le Programme C d'Exemple

Nous étudions l'évolution de la mémoire tout au long de ce fragment de code canonique :

tracage_memoire.c 
const int array_size = 5;
int *array = NULL;

// Étape 1 : Réservation de 20 octets sur le Heap
array = (int *) malloc(array_size * sizeof(int));

// Étape 2 : Initialisation par arithmétique des pointeurs
for (int i = 0; i < array_size; ++i) {
    *(array + i) = i * i;
}

// Étape 3 : Restitution au système
free(array);

// Étape 4 : Neutralisation du pointeur suspendu
array = NULL;
ÉTAPE 1

📦 Allocation Initiale avec malloc

L'appel à malloc(5 * sizeof(int)) demande au système 20 octets consécutifs. La fonction renvoie l'adresse de départ du bloc alloué (par exemple @0x55a0).

  • La variable pointeur array est située sur la Pile (Stack) à l'adresse locale @0x7ffc....
  • Elle contient l'adresse @0x55a0 qui pointe vers le bloc réservé sur le Tas (Heap).
  • Important : malloc n'initialise pas la mémoire ! Les 5 entiers contiennent des valeurs arbitraires imprévisibles (garbage values).

ÉTAPE 3

⚠️ Libération avec free(array) et Danger Suspendu

L'appel à free(array) informe le gestionnaire de mémoire que le bloc @0x55a0 est désormais disponible pour de futures allocations.

🚨 Le Piège Mortel du Pointeur Suspendu (Dangling Pointer)
free() libère la zone du Tas mais ne modifie absolument pas la variable array ! Le pointeur array contient toujours l'adresse @0x55a0, qui n'est plus valide. Tenter de lire ou d'écrire dedans provoque une faille critique de type Use-After-Free (UAF).

ÉTAPE 4

🛡️ La Neutralisation Défensive : array = NULL;

Pour neutraliser définitivement le pointeur suspendu, on assigne la constante NULL (adresse 0) à la variable.

📦 Pile (Stack)

array @0x7ffc80
Valeur sécurisée :
NULL (0x0) ✅

Si un bout de code tente ultérieurement de déréférencer *array, le noyau Linux lèvera instantanément une faute de page (SIGSEGV propre et immédiat), empêchant toute exploitation silencieuse ou corruption mémoire pernicieuse.

🔄 Machine à États du Pointeur Sécurisé

1. Déclaration int *ptr = NULL;
NULL (Sûr)
2. Après malloc ptr = malloc(...);
VALIDE
3. Après free free(ptr);
SUSPENDU ⚠️
4. Après reset ptr = NULL;
DÉSARMÉ ✅
