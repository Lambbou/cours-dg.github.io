📌 Synthèse : Les 4 commandements de l'allocation dynamique en C

1. Réserver & Vérifier (`malloc`)

malloc(sizeof(T)) découpe un bloc dans le Tas et renvoie son adresse de début. Le contenu initial est indéterminé (garbage 0x??). Vérifiez toujours que le retour n'est pas NULL.

2. Déréférencer (`*p = val`)

Le pointeur p réside sur la Pile mais pointe vers le Tas. Écrire *p = 42 suit la flèche pour remplir les octets du casier sur le Tas.

3. Rendre les clés (`free`)

Si la fonction se termine et détruit p sur la Pile sans avoir appelé free(p), le casier sur le Tas devient orphelin : c'est une Fuite Mémoire (Memory Leak).

4. Neutraliser (`p = NULL`)

free(p) détruit le casier mais ne modifie pas la valeur de p ! p devient un Dangling Pointer. Assignez immédiatement p = NULL; pour éviter tout Use-After-Free.
