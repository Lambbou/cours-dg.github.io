Allocation Dynamique et Accès Mémoire en C 🧠

Cette page décompose le fonctionnement de l'allocation de mémoire dynamique, son accès via l'arithmétique des pointeurs, et sa libération. Nous utiliserons l'extrait de code C suivant comme exemple :

const int array_size = 5;
int *array;
array = (int *) malloc( array_size * sizeof(int) );

for (int i = 0; i < array_size; ++i) {
    *(array + i) = i * i;
}

free(array);
array = NULL;

Étape 1 : L'Allocation avec malloc

La première étape consiste à demander de la mémoire au système d'exploitation.

array = (int *) malloc( array_size * sizeof(int) );
  • malloc (memory allocation) réserve un bloc de mémoire sur une zone appelée le tas (heap).
  • array_size * sizeof(int) calcule la taille totale nécessaire : 5 fois la taille d'un entier (par exemple, 5 * 4 = 20 octets).
  • malloc retourne l'adresse du début de ce bloc.
  • Cette adresse est stockée dans notre pointeur array, qui lui, se trouve sur la pile (stack).

Étape 2 : Accès et Initialisation avec la Boucle for

Maintenant, nous allons remplir ce bloc mémoire en utilisant une boucle et l'arithmétique des pointeurs.

*(array + i) = i * i;

Décortiquons cette ligne cruciale :

  • array + i: C'est le cœur de l'arithmétique des pointeurs. Cela ne signifie pas "adresse de base + i octets". Le compilateur sait que array est un pointeur vers des int. Donc, array + i signifie : "aller à l'adresse de base et avancer de i cases de la taille d'un int".
  • *( ... ): L'opérateur de déréférencement. Il signifie : "accéder à la valeur qui se trouve à l'adresse calculée entre les parenthèses".

Étape 3 : Libération de la Mémoire avec free

La mémoire allouée sur le tas ne se nettoie pas toute seule ! Nous devons la rendre explicitement au système.

free(array);
  • free() prend en argument un pointeur qui a été retourné par malloc.
  • Elle informe le système que le bloc de mémoire pointé par array est maintenant disponible et peut être réutilisé.
  • Attention : Après free(array), le pointeur array lui-même contient toujours l'ancienne adresse ! C'est ce qu'on appelle un pointeur suspendu (dangling pointer). Tenter de l'utiliser est une grave erreur qui peut faire planter le programme.

Ce bloc est maintenant marqué comme "disponible" par le système.

Étape 4 : La Bonne Pratique : array = NULL;

Pour éviter les problèmes liés aux pointeurs suspendus, il est recommandé de mettre le pointeur à NULL juste après avoir libéré la mémoire.

array = NULL;
  • NULL est une valeur spéciale (souvent 0) qui signifie "ce pointeur ne pointe sur rien de valide".
  • Cela permet de vérifier plus tard si le pointeur est utilisable (ex: if (array != NULL)) et empêche son utilisation accidentelle.
